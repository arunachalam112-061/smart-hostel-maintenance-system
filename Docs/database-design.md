# Database Design

Core entities:
- `users`: account details and role.
- `complaints`: issue title, description, category, location, status, student and assigned staff.
- `notifications`: messages linked to a user.
- `maintenance_history`: status changes and notes.
- `feedback`: rating and comments for resolved complaints.

See `database/schema.sql` for the SQL schema and `database/sample-data.sql` for demo records.

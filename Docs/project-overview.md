# Project Overview

## Smart Hostel Maintenance System
The system digitizes maintenance requests in a hostel. Students submit complaints about electrical, plumbing, cleaning, room, or facility issues. Staff can view assigned work and update progress. Administrators can review complaints, manage users, and monitor maintenance activity.

## Objectives
- Reduce the time required to report and resolve hostel issues.
- Keep complaint status visible to students.
- Help administrators assign and track maintenance work.
- Maintain complaint history and feedback.

## User roles
- Student: create complaints, check status, receive notifications, submit feedback.
- Staff: view assigned complaints and update status.
- Admin: oversee complaints and staff activity.

## Scope note
This repository is a working academic starter. Authentication and authorization must be hardened before any real deployment.
